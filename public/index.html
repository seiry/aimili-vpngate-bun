SOCKS5 代理导出与使用示例

当前节点已建立 SSL-VPN 隧道，所有连接到本 SOCKS5 / HTTP 代理端口的流量均经由远端出口节点加密穿透。

SOCKS5h (远程 DNS 解析防泄漏):
socks5h://127.0.0.1:1080
HTTP / HTTPS 代理:
http://127.0.0.1:1080
cURL 命令行测试:
curl --proxy socks5h://127.0.0.1:1080 https://api.ipify.org
Linux Shell 环境变量:
export all_proxy="socks5://127.0.0.1:1080"
